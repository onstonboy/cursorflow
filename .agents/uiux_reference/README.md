This documentation is extracted from ui-ux-pro-max projects (https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

Purpose is to provide more context for AI in this flow.

## How to use (required before implementing features)

- Review these UI/UX references before implementing any new feature that touches UI, UX, layout, content hierarchy, or interaction patterns.
- Use them alongside any project-specific artifacts (requirements/specs, existing screens, design images, design system/Figma).

## What’s inside

- `.agents/uiux_reference/data/`: UI reference data (styles, colors, typography, UX guidelines, `landing.csv`, `prompts.csv`, stacks).
- `.agents/uiux_reference/landing_page_prompts/`: style prompts library (see the `README.md` index in that folder).
